# Dizajn ekrana (referenca)

Ovo su makete iz Claude Design platna „Stolarska aplikacija — kuhinja". Fajlovi `.dc.html` su HTML za alat za dizajn (koriste `support.js` koji ovde ne postoji), pa ih čitaj kao referencu za izgled, raspored, tekst i boje — ne kopiraj ih kao kod aplikacije.

Vizuelni jezik:
- Fontovi: IBM Plex Sans (UI), IBM Plex Mono (sve mere i brojevi)
- Pozadina #F3F1EC, paneli #FFFFFF, linije #DDD8CE, tekst #1C1B19, sekundarni tekst #5F5A52
- Akcenat #B4440E (svetliji na tamnom #E2804D), tamna traka #1C1B19
- Instalacije: voda #1E50C8, odvod #57534E, struja #F2B630 (crn tekst), gas #B4440E
- Mere u tabelama poravnate desno, monospace
